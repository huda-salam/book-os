# Epistemic Model

Book OS requires authors and editors to distinguish different kinds of knowledge.

| Type | Meaning |
|---|---|
| Fact | A claim supported by appropriate evidence |
| Assumption | A proposition accepted for reasoning but not established as fact |
| Evidence | Information used to support, challenge, or qualify a claim |
| Inference | A conclusion derived from available information |
| Interpretation | Meaning assigned to evidence or observations |
| Judgment | A reasoned conclusion |
| Recommendation | A proposed action based on requirements, evidence, constraints and trade-offs |
| Unknown | Something not sufficiently established |

Do not use citation merely as decoration. A source demonstrates provenance; it does not automatically establish truth, applicability, causality, or recommendation.

### Confidence is not evidence

Confidence describes how strongly a conclusion is held. It does not substitute for evidence.

### Uncertainty

When evidence is insufficient, state what is unknown and, where useful, identify **how it could be known**.
