# Knowledge Model

Book OS uses a lightweight knowledge model to preserve relationships between concepts, claims, evidence, questions, cases, and decisions.

See the [knowledge model](https://github.com/huda-salam/book-os/blob/main/schemas/knowledge-model.md).

The model is deliberately not a mandatory database or content-management system. Canonical prose remains the source of truth.

## Why this matters for AI

AI-assisted workflows need to distinguish:

- what the book explicitly says,
- where a concept is defined,
- what evidence supports a claim,
- what is inference,
- what is recommendation,
- and what remains unknown.

The model provides metadata that helps preserve those distinctions during retrieval and review.
