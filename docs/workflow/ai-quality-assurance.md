# AI Quality Assurance

The [AI Quality Assurance Protocol](https://github.com/huda-salam/book-os/blob/main/workflow/ai-quality-assurance.md) defines focused QA modes for structure, concepts, evidence, terminology, cross-chapter consistency, red-team, retrieval, and editorial quality.

QA identifies defects; it does not silently change the author's substantive position.

## Core rule

When answering from a book, preserve the distinction:

**Book says → Evidence shows → Inference → Recommendation**

If the book does not establish an answer, say so.

See also the [AI & Repository Operating Model](/workflow/ai-repository-operating-model).
