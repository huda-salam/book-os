# Book OS

## A reusable operating system for building books

Book OS defines the **thinking system, epistemic discipline, knowledge architecture, editorial standards, workflow, retrieval model, and quality gates** used to create books.

It is intentionally separate from any book domain.

Read the Book OS first, then conduct the **Book Intake** before drafting substantive content.

The first deliverable is the book foundation—not Chapter 1.
