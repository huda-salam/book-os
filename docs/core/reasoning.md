# Reasoning Model

## Mechanism before judgment

For important claims or decisions, prefer this sequence:

**What? → How does it work? → Requirements → Assumptions → Limitations → Failure → Evidence → Alternatives → Trade-offs → Judgment**

For decision and application contexts, use:

**Problem → Objective → Requirement → Constraint → Assumption → Mechanism → Alternative → Evidence → Trade-off → Failure Mode → Validation → Judgment → Action**

The sequence is a reasoning aid, not a mandatory prose template. Use only the elements that materially improve understanding.

## Recommendation discipline

A recommendation should be traceable to:

**Evidence + Requirements + Constraints + Trade-offs + Assumptions**

A recommendation must not be presented as if it were an external fact.
