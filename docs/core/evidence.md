# Evidence Architecture

Important claims should be traceable through:

**Claim → Claim Type → Source → Version/Date → Evidence Strength → Evidence Boundary → Interpretation → Implication**

## Source hierarchy

Choose evidence according to the claim. Possible source classes include:

- primary sources,
- official sources,
- standards and regulations,
- peer-reviewed research,
- empirical evidence,
- industry evidence,
- expert analysis,
- secondary reporting,
- anecdote.

Source class does not automatically determine truth. Applicability, scope, date, jurisdiction, version, and methodological limitations matter.

## Case studies

A case should teach more than an outcome. Where relevant, capture:

- mechanism,
- decision,
- trade-off,
- failure,
- implementation reality,
- unintended consequence,
- organizational consequence,
- evidence limitation,
- counterexample.

One case is not universal proof.
