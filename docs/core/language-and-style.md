# Language & Style System

Language is a presentation layer over the same underlying knowledge.

A book may serve readers with very different attention spans and levels of seriousness without creating different factual standards.

## 1. Separate substance from expression

Keep these stable:

- facts,
- evidence,
- assumptions,
- uncertainty,
- scope,
- mechanisms,
- causal relationships,
- conceptual definitions,
- trade-offs,
- recommendations and their rationale.

Allow these to vary:

- vocabulary density,
- sentence length,
- rhythm,
- narrative,
- examples,
- metaphors,
- visual breaks,
- amount of context,
- degree of informality.

## 2. Reader profiles

Book OS supports multiple profiles.

### Professional / Executive

Characteristics:

- concise,
- structured,
- high information density,
- explicit implications,
- low tolerance for unnecessary narrative.

Useful patterns:

**Context → Insight → Evidence → Implication → Decision**

### Technical / Practitioner

Characteristics:

- mechanism-oriented,
- precise terminology,
- implementation examples,
- constraints and failure modes.

Useful patterns:

**Problem → Mechanism → Example → Failure → Trade-off → Practice**

### Accessible / General

Characteristics:

- plain language,
- short conceptual units,
- concrete examples,
- progressive terminology introduction,
- frequent "why this matters" explanations.

Useful patterns:

**Hook → Question → Simple model → Example → Deeper explanation → Takeaway**

### Youth / High-Attention-Sensitivity

This profile should not mean "less serious".

Use:

- shorter sections,
- strong openings,
- concrete scenarios,
- conversational transitions,
- visual hierarchy,
- occasional analogy,
- varied rhythm,
- explicit takeaways.

Avoid:

- fake slang,
- forced memes,
- excessive emojis,
- artificial attempts to sound young,
- simplifying away important nuance.

The content standard remains unchanged.

## 3. Layered writing

When audience diversity is high, prefer layered writing over a single compromise style.

A useful pattern:

**Fast Layer → Core Layer → Deep Layer**

### Fast Layer

Answers:

- Why should I care?
- What is the key idea?
- What should I remember?

### Core Layer

Explains:

- concept,
- mechanism,
- evidence,
- implication.

### Deep Layer

Provides:

- assumptions,
- edge cases,
- alternatives,
- trade-offs,
- failure modes,
- evidence limitations.

This allows a younger or impatient reader to enter quickly without preventing a serious reader from going deeper.

## 4. Style profile

Every new book should define a style profile.

Suggested fields:

- language,
- regional variant,
- audience profile,
- formality,
- information density,
- sentence rhythm,
- terminology density,
- narrative intensity,
- example frequency,
- visual break frequency,
- humor policy,
- metaphor policy,
- accessibility target,
- technical depth.

## 5. Style invariants

Changing style must never silently change:

- certainty,
- evidence strength,
- factual status,
- scope,
- assumptions,
- causality,
- limitations,
- recommendation strength.

For example, a conversational sentence such as "This always works" is not an acceptable stylistic rewrite of a source-backed claim that says "This may improve outcomes under specific conditions."

## 6. Editorial principle

**Make the doorway easier, not the knowledge weaker.**

A younger reader can receive a compelling opening, a practical example, and short sections while still being led toward the same rigorous conceptual core.

The goal is not to write for everyone in one voice.

The goal is to make the same trustworthy knowledge accessible through appropriate entry points.
