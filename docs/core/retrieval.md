# Retrieval

Book OS supports two complementary modes:

### Learning Mode

A reader follows the conceptual progression of the book.

### Retrieval / Advisory Mode

A reader starts with a question, case, claim, or decision and navigates to the canonical knowledge needed to answer it.

Useful navigation patterns include:

- Question-First
- Case-First
- Claim / Red-Flag
- Concept-First

Navigation reduces search time. It must not replace reasoning.

The book should also make important cross-references explicit so readers and future AI systems can retrieve knowledge without losing its epistemic meaning.
