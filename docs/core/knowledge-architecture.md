# Knowledge Architecture

The book should have a coherent model of its knowledge.

A useful conceptual model may include:

- Knowledge Base
- Document
- Document Version
- Chapter
- Section
- Concept
- Claim
- Evidence
- Source
- Case
- Question
- Framework
- Example
- Counterexample
- Cross-reference

This is a conceptual model, not a requirement to implement a database.

## Canonical knowledge ownership

Each important concept should have one canonical home.

Other chapters may:

- apply it,
- compare it,
- critique it,
- extend it,
- or reference it.

They should not silently redefine it.

## Knowledge progression

Where appropriate, guide readers through:

**understanding → connecting → questioning → analyzing → evaluating → applying → judgment → action**
