# Canonical Ownership & Cross-Reference Rules

## Purpose

Canonical ownership prevents the same concept, definition, claim, or rule from acquiring different meanings in different parts of a book.

The rule is simple:

> An important idea should have one canonical home. Other locations may explain, apply, compare, critique, or retrieve it without silently redefining it.

## What Requires Canonical Ownership

Canonical ownership should be considered for:

- important concepts and terms;
- normative or operational definitions;
- central claims;
- mechanisms and causal relationships;
- major frameworks;
- important assumptions;
- recurring rules or principles;
- material recommendations;
- evidence interpretations that materially affect the book's position.

Not every sentence needs ownership. Apply the rule where inconsistency could change reader understanding or application.

## Canonical Home

A canonical home is the location where the book defines or establishes the authoritative internal meaning of an idea.

A canonical home should normally contain:

- canonical name;
- meaning;
- scope;
- what it does not mean;
- important related terms;
- assumptions or boundaries;
- evidence where relevant;
- relationship to adjacent concepts;
- stable cross-reference identity when useful.

The canonical home is not necessarily the first place where the idea appears. It is the location deliberately chosen to own its meaning.

## Use vs Own

A chapter may:

- introduce a concept provisionally;
- use an established concept;
- apply it to a case;
- compare it with alternatives;
- challenge an assumption;
- discuss consequences;
- provide an example;
- retrieve it for a reader question.

These uses do not create a second canonical definition.

When a concept already has a canonical home, prefer:

**Define once → Reference → Apply → Extend only with explicit ownership change.**

## Introducing New Concepts

When a new important concept appears, ask:

1. Is it genuinely new?
2. Does an existing concept already cover the meaning?
3. Would creating a new term create unnecessary distinction?
4. Which chapter is responsible for owning it?
5. What downstream chapters depend on it?

Avoid artificial terminology created merely to make a framework appear more sophisticated.

## Changing a Canonical Meaning

A canonical meaning must not be silently changed.

A proposed change should identify:

- current meaning;
- proposed meaning;
- reason for change;
- affected chapters;
- affected claims and evidence;
- terminology impact;
- retrieval impact;
- migration or compatibility action.

Material changes require explicit review before adoption.

## Cross-Reference Rules

Cross-references should point readers toward canonical knowledge rather than duplicate it.

A useful cross-reference states:

- what is being referenced;
- why the reader needs it here;
- where the canonical treatment lives.

Avoid cross-reference chains that force readers through multiple intermediate chapters.

Prefer:

**Current question → Canonical source**

over:

**Current question → Chapter A → Chapter B → Chapter C**

## Local Explanation

A chapter may repeat a short explanation when necessary for readability.

The repetition is acceptable when it:

- preserves the canonical meaning;
- does not introduce competing scope;
- points to the canonical source when useful;
- adds local context rather than a second definition.

## Evidence Ownership

Evidence belongs to the claim or concept it supports, not merely to the chapter where it was discovered.

If the same evidence supports multiple chapters:

- maintain one authoritative evidence record where practical;
- reference it from other locations;
- preserve source version/date and evidence boundaries;
- do not change evidence strength merely because the context changed.

Interpretation may differ by context, but the difference must be explicit.

## Claim Ownership

A central claim should have a traceable home.

Other chapters may:

- use the claim;
- provide supporting evidence;
- provide counterevidence;
- explain implications;
- test boundary conditions.

If another chapter materially changes the claim, treat it as a change request rather than a local rewrite.

## Cross-Chapter Dependency

When one chapter depends materially on another, record the dependency when it affects:

- terminology;
- assumptions;
- mechanism;
- evidence;
- conclusions;
- reader progression.

Dependencies should point from the using location to the canonical owner.

## Conflict Resolution

When two sections appear to disagree:

1. determine whether they use the same term;
2. compare definitions and scope;
3. compare assumptions;
4. compare populations, contexts, and time periods;
5. compare evidence;
6. determine whether the disagreement is substantive or terminological;
7. resolve or preserve the disagreement explicitly.

Never resolve a contradiction by silently changing one section.

## Retrieval Implications

Canonical ownership improves retrieval.

A future reader or AI assistant should be able to answer:

- Where is this concept defined?
- What does the book mean by it?
- What assumptions bound it?
- Which claims depend on it?
- What evidence supports it?
- Where is it applied?
- Where is it challenged?
- What would change the book's position?

Retrieval should distinguish the canonical definition from later applications and commentary.

## Ownership Record

For important concepts, use a lightweight ownership record:

| Field | Purpose |
|---|---|
| Concept | Canonical name |
| Owner | Canonical chapter/section |
| Definition | Stable meaning |
| Scope | Where it applies |
| Non-meaning | Important exclusions |
| Dependencies | Concepts it relies on |
| Evidence | Relevant evidence records |
| Used by | Major dependent chapters |
| Status | Draft / Stable / Deprecated |
| Last reviewed | Maintenance date |

Do not create records for trivial ideas.

## Quality Gate

Before release, verify that:

- central concepts have clear owners;
- competing definitions are resolved or explicitly distinguished;
- cross-references point toward canonical knowledge;
- material changes have impact analysis;
- evidence is not duplicated with conflicting strength;
- local explanations do not silently redefine canonical concepts;
- retrieval can distinguish definition, application, critique, and recommendation.

## Governing Principle

**Canonical ownership protects meaning; cross-reference protects coherence; explicit change protects intellectual integrity.**
