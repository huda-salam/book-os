# Schemas

Schemas are optional infrastructure.

Use structured metadata only when it creates real value for:

- consistency,
- validation,
- retrieval,
- traceability,
- maintenance,
- AI-assisted quality assurance.

Do not turn Book OS into a database project.

The conceptual model is defined in [knowledge-model.md](./knowledge-model.md).

A future machine-readable schema may use YAML or JSON, but should be introduced only after real book projects demonstrate a stable need.
